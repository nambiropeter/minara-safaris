# Development placeholder imagery

**Every file here is stock and must be gone before launch.** Sourced from Pexels,
downscaled to 2400px on the long edge by `pnpm optimize:images` — run it after
dropping anything new in here; it rewrites in place and skips what's already
under the cap. They exist so layout and
crops can be judged against real photographs instead of grey boxes.

Minara does not own these trips, vehicles, or camps — see `PRODUCT.md`, Evidence
on Hand. Nothing here may appear in a context that implies it is Minara's own
operation.
